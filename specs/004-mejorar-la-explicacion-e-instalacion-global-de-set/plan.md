### Decisión de contrato — lanzamiento global dual

- **Rutas candidatas.** Resolver `~` contra el HOME efectivo. Claude Code es candidato únicamente si existe `~/.claude/`; su destino es `~/.claude/commands/setup-ai.md`. Codex es candidato si existe `~/.codex/`, con destino preferente `~/.codex/skills/setup-ai/SKILL.md`; solo si `~/.codex/` no existe y sí existe `~/.agents/`, usar `~/.agents/skills/setup-ai/SKILL.md`. Se pueden crear los subdirectorios del artefacto dentro de una raíz ya detectada, pero nunca crear una raíz de agente para hacerla pasar por detectada. Esta prioridad adopta `tech-spec.md` (actualizado el 2026-08-07), que sustituye la fila histórica de `product-spec.md` que solo nombra `~/.agents/skills`.
- **Precondición y parada.** Comprobar las dos candidaturas antes de mostrar/aceptar la única autorización y antes de escribir. Si falta una o ambas, no copiar ninguna plantilla y cerrar Step 6 con: `Global setup-ai launcher not installed: missing Claude Code path (~/.claude/)`, `missing Codex path (~/.codex/ or ~/.agents/)`, o ambas causas en la misma respuesta; añadir que se requiere instalar o inicializar el agente correspondiente y volver a ejecutar `setup-ai`. No ofrecer una instalación parcial ni pedir elegir un agente.
- **Detección posterior.** Para cada copia, verificar que existe el fichero exacto en su destino, que sus bytes son los de su plantilla nativa y que conserva la forma reconocible por el agente: comando Markdown con frontmatter de Claude en `commands/setup-ai.md`, o directorio de skill Codex con `SKILL.md` y `name: setup-ai`. Después intentar la comprobación de descubrimiento disponible en la sesión del agente; si la sesión o versión no expone una lista/recarga de comandos o skills, informar explícitamente que la verificación quedó limitada a la estructura y bytes esperados, no declarar detectabilidad de ejecución. Si el agente sí expone la comprobación y no encuentra el lanzador, informar el agente, la ruta escrita y el resultado concreto de la comprobación. Una verificación fallida no borra ni revierte la otra copia.
- **Límite.** Esta feature reemplaza la oferta futura por el par global y no migra, borra ni altera lanzadores históricos fuera de esas dos escrituras aprobadas.
