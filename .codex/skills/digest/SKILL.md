# Digest

Use the user's language. Clarify only missing essentials, with at most three short questions: what to investigate, which evidence matters, and which decision it will inform. Then perform light, current research using three to six relevant sources.

State evidence and uncertainty distinctly. Do not write code or specs. Conclude with: a concise synthesis, a recommended path with rationale and tradeoffs, and a viable option B with when it is preferable. Cite every time-sensitive factual claim with direct links.
